# WhiteKnight（仮称）

中小企業・自治体・大学研究室が、**自分たちが管理する** Web サービスと GitHub リポジトリの弱点を、専門家がいなくても見つけて直せる診断ツールです。結果は「危険度・何が問題か・どう直すか」を、専門用語を使わない日本語で伝えます。

> 開発状況：**M1（土台）**。診断ルールの定義・日本語テンプレート・レポート生成・AI 利用方針の制御・Web アプリの骨組みまでができています。実際の診断（リポジトリ・Web）は M2〜M3 で実装します。詳しくは [docs/DESIGN.md](docs/DESIGN.md)。

## 倫理と利用範囲

このツールは**防御のための道具**です。次の範囲を守ることを、仕組みと利用規約の両方で担保します。

### 診断してよいもの
- **あなた（またはあなたの組織）が所有・管理している** GitHub リポジトリと Web サイトだけです。
- リポジトリ：GitHub App を**あなた自身が**インストールし、かつあなたがそのリポジトリの管理者（admin / maintain）であることを確認してから診断します。
- Web サイト：**DNS TXT レコード**または**確認用ファイルの設置**で所有を確認できたホスト名だけを診断します。確認は診断のたびにやり直し、確認できなくなったら診断を止めます。

### このツールがしないこと
- 他人のシステムの診断・スキャン（所有確認の仕組みを回避する手段も提供しません）
- 攻撃コード・エクスプロイトの作成や実行、攻撃文字列の送信、ログインの試行、認証の回避
- ポートスキャン、ディレクトリの総当たり、リンクを辿る巡回（クロール）
- 相手のサーバーに負荷をかける操作（Web 診断は 1 サイトあたり最大約 30 リクエスト、1 秒に 1 回まで、`GET`/`HEAD` のみ。User-Agent で WhiteKnight からのアクセスだと分かるようにしています）

### 診断結果の取り扱い
- 見つかったパスワードや API キーは**伏せ字にした形でだけ**保存・表示・通知します。元の値は保存しません。
- 公開されてしまっているファイル（`.env` など）を見つけても、その中身は保存しません。
- 見つかった問題は、あなたの組織のメンバーにだけ表示します。

### 外部 AI の利用（既定は「使わない」）
- **既定では外部 AI を一切使いません。** ルールに基づく診断と、人が書いた日本語の説明だけでレポートが完成します。
- AI は組織ごとにオプションで有効にできます。

  | モード | 外部 AI に送るもの |
  | --- | --- |
  | `off`（既定） | 何も送らない |
  | `metadata_only`（**外部AIへコードを送らない**） | 問題の種類・危険度・ファイル名/URL・利用技術の名前だけ |
  | `with_code` | 上に加えて問題箇所の前後のコード（秘密情報は伏せ字にしてから）。秘密情報に関する指摘ではコードを送らない |

- 自治体などで、設置環境としてこれを強制したい場合は、環境変数で上限を設定できます。組織の設定よりも常に優先されます。
  - `WHITEKNIGHT_AI_HARD_DISABLE=true` … 外部 AI を一切呼ばない
  - `WHITEKNIGHT_AI_MAX_MODE=metadata_only` … 外部 AI へコードを送らない
- レポートの末尾には、外部 AI を使ったかどうか・何を送ったかを必ず記載します。

### 利用者へのお願い
- 所有・管理していない対象を診断しようとしないでください。不正アクセス禁止法などの法令に違反する可能性があります。
- 委託先（制作会社・ホスティング事業者）が管理している環境を診断する場合は、事前に委託先の了承を得てください。
- このツールで見つからなかったことは、「安全である」ことの保証ではありません。

## 開発

必要なもの：Node.js 22 以上、pnpm 10

```bash
pnpm install
```

```bash
pnpm check
```

`pnpm check` は lint・型チェック・テストをまとめて実行します。Web アプリの起動は次のとおりです。

```bash
pnpm --filter @whiteknight/web dev
```

### 構成

| パス | 内容 |
| --- | --- |
| `packages/core` | 型、危険度、fingerprint、秘密情報のマスク、診断エンジン、差分判定、**外部AI利用方針** |
| `packages/rules` | ルール一覧（37 項目）、やさしい日本語のテンプレート、レポート（Markdown）生成 |
| `apps/web` | Next.js（App Router）。自分自身にも厳しいセキュリティヘッダ（nonce 付き CSP など）を適用 |
| `docs/` | 設計書、名称調査 |
